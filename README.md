# 🎄 산타 치와와의 크리스마스 배달 작전 (Chihuahua's Christmas Delivery) 🐾🎁

귀여운 산타 치와와가 눈 내리는 성탄절 밤, 지붕 위를 신나게 달리며 착한 아이들의 집 굴뚝으로 선물을 배달하는 횡스크롤 아케이드 웹 게임입니다.

🌐 **웹에서 바로 플레이하기**: [https://ddikui.github.io/chihuahua-christmas-delivery/](https://ddikui.github.io/chihuahua-christmas-delivery/)

---

## 🎮 게임 특징
- **귀여운 산타 치와와 캐릭터**: 큰 쫑긋 귀와 똘망똘망한 눈망울, 빨간 산타 모자와 선물 보따리를 메고 총총총 달리는 애니메이션!
- **선물 배달 시스템**: 달리는 관성을 이용해 지붕의 굴뚝 속으로 선물을 쏙 떨어뜨리면 배달 성공!
- **연속 배달 콤보 (Combo)**: 연속으로 굴뚝에 골인할 때마다 콤보 보너스 획득!
- **2단 점프 액션**: 지붕 사이를 건너뛰거나 장애물(눈사람)을 피하기 위한 더블 점프!
- **크리스마스 캐롤 BGM & 사운드**: Web Audio API로 구현한 징글벨(Jingle Bells) 멜로디 및 풍성한 사운드 이펙트.
- **모바일/터치 지원**: 화면 터치 및 하단 버튼으로 모바일 기기에서도 완벽 조작.

---

## 🕹️ 조작 방법
| 동작 | 키보드 | 마우스 / 화면 터치 |
| :--- | :--- | :--- |
| **점프 / 2단 점프** | `Space` / `↑` / `W` | 좌측 화면 클릭 / **🦘 점프** 버튼 |
| **선물 투하** | `↓` / `S` / `D` | 우측 화면 클릭 / **🎁 선물 투하** 버튼 |
| **BGM 음소거** | 상단 버튼 클릭 | 상단 **🎵 BGM ON/OFF** 버튼 |

---

## 🚀 실행 방법
별도의 설치나 빌드 과정 없이, 웹 브라우저(Chrome, Safari, Edge 등)에서 `index.html` 파일을 더블 클릭하거나 여시면 즉시 플레이할 수 있습니다.

```bash
# macOS에서 브라우저로 바로 열기
open index.html
```
